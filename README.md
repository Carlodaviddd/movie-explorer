# Movie Explorer
Is a mobile application developed using **React Native** and **Expo**, inspired by IMDb. It allows users to discover, search, and save favorite movies while exploring movie information such as posters, ratings, release dates, genres, and descriptions through the **TMDB API**.

## Technologies Used
- `React Native`
- `Expo`
- `Javascript`
- `TMDB API`

## Features
- Browse popular, trending, and top-rated movies.
- Search for movies by title.
- View movie posters, ratings, release dates, genres, and descriptions
- Save and manage favorite movies.
- Explore movies across different categories.

## Installation and Setup
1. Clone the repository
2. Navigate to the project folder
3. Install dependencies: `npm install`
4. Run development server: `npx expo start`
5. Run the application using ``Expo Go``, and Android emulator.
